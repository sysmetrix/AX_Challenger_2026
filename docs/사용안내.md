# AX 챌린저 성과보고 웹페이지 사용 안내

발표자료(재단 서식 24장)를 반영했습니다. 압축 파일을 한 폴더에 모두 풀고 **index.html**을 Edge 또는 Chrome으로 여세요. 폴더의 `assets`, `media`, `downloads`와 JavaScript·CSS 파일은 함께 유지해야 합니다.

1. **경과·성과**: 숫자 실적을 선택하면 근거가 열립니다. 추진 단계·정기모임을 선택하면 설명과 주요 결정사항이 바뀌고, 주요 이정표는 기반·도구·워크숍으로 걸러 볼 수 있습니다. 전략경영실 프로덕트와 업무유형별 목록의 항목도 근거로 연결됩니다.
2. **전체 사례**: 검색어, 부서, 단계와 업무 유형을 함께 선택할 수 있습니다. ‘전체 30개 보기’를 누르면 전체 탐색 항목이 표시됩니다. 사례를 선택하면 효과·상태·출처·해석 범위를 확인할 수 있습니다.
3. **시연·체험**: 영상의 재생 버튼이나 오른쪽 구간 설명을 선택하세요. 예제 체험의 조건을 바꾸면 결과가 달라집니다. 원본 운영 시스템에 연결되지 않으며 입력을 저장·전송하지 않습니다.
4. **챌린저**: 15명 전원의 이름을 선택해 확인된 기여와 부서 활동을 확인합니다.
5. **추진체계**: 2026년 현황과 2027년 설계 제안을 비교하고 도식을 확대하거나 SVG로 내려받습니다.
6. **2027**: 추진 방향·4주 육성과정·연간 추진 흐름을 선택해 세부 설명을 확인합니다. 규모·운영 방식은 검토안입니다.
7. **근거·자료**: 원문 출처를 펼쳐 보고 발표자료 PDF를 내려받습니다.

내용이 많은 표·목록은 필요한 부분만 펼쳐 사용하세요.

영상은 수입관리 **실제 로컬 프로그램 + 가상자료 녹화 30초**, 안전교육일지 **설명용 재구성 23초**로 구분합니다. 무음이며 화면 설명과 한국어 자막을 제공합니다. 자막 파일의 로컬 접근이 제한되면 영상 자체의 설명·구간 설명을 이용하세요. 외부 원문 링크에는 인터넷과 해당 자료의 열람 권한이 필요합니다.

30개는 사례목록의 탐색 항목이며 확정 완료 프로젝트 수가 아닙니다. 조사 수치는 응답자 기준이고, 2027년 계획·4주 과정은 검토안입니다. 자료 기준일은 2026년 10월 4일입니다.
